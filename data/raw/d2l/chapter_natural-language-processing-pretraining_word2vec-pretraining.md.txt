The Skip-Gram Model.

We implement the skip-gram model by using embedding layers and batch matrix multiplications. First, let's review how embedding layers work.

Embedding Layer.

As described in section <num>, an embedding layer maps a token's index to its feature vector. The weight of this layer is a matrix whose number of rows equals to the dictionary size (<code>) and number of columns equals to the vector dimension for each token (<code>). After a word embedding model is trained, this weight is what we need.

The input of an embedding layer is the index of a token (word). For any token index <math>, its vector representation can be obtained from the <math> row of the weight matrix in the embedding layer. Since the vector dimension (<code>) was set to 4, the embedding layer returns vectors with shape (2, 3, 4) for a minibatch of token indices with shape (2, 3).

Defining the Forward Propagation.

In the forward propagation, the input of the skip-gram model includes the center word indices <code> of shape (batch size, 1) and the concatenated context and noise word indices <code> of shape (batch size, <code>), where <code> is defined in section <num>. These two variables are first transformed from the token indices into vectors via the embedding layer, then their batch matrix multiplication (described in section <num>) returns an output of shape (batch size, 1, <code>). Each element in the output is the dot product of a center word vector and a context or noise word vector.
