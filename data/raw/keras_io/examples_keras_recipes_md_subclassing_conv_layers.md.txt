Customizing the convolution operation of a Conv2D layer.

Introduction.

You may sometimes need to implement custom versions of convolution layers like <code> and <code>. Keras enables you do this without implementing the entire layer from scratch: you can reuse most of the base convolution layer and just customize the convolution op itself via the <code> method.

This method was introduced in Keras 2.7. So before using the <code> API, ensure that you are running Keras version 2.7.0 or greater.

A Simple <code> implementation.

There are two ways to use the <code> API. The first way is to override the <code> method on a convolution layer subclass. Using this approach, we can quickly implement a StandardizedConv2D as shown below.

The other way to use the <code> API is to directly call the <code> method from the <code> method of a convolution layer subclass. A comparable class implemented using this approach is shown below.
