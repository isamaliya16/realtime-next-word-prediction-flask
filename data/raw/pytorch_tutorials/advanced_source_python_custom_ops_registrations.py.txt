Adding training support for NumPy sin Use <code> to add training support for an operator. Prefer this over directly using <code>; some compositions of <code> with PyTorch operator registration APIs can lead to (and has led to) silent incorrectness when composed with <code>.

If you don't need training support, there is no need to use <code>. If you end up training with a <code> that doesn't have an autograd registration, we'll raise an error message.

This page uses the same <code> operation as the functional and mutable pages so the only new concept is the autograd registration.
