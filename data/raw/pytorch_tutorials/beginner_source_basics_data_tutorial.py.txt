Datasets & DataLoaders.

Code for processing data samples can get messy and hard to maintain; we ideally want our dataset code to be decoupled from our model training code for better readability and modularity. PyTorch provides two data primitives: <code> and <code> that allow you to use pre-loaded datasets as well as your own data. <code> stores the samples and their corresponding labels, and <code> wraps an iterable around the <code> to enable easy access to the samples.

PyTorch domain libraries provide a number of pre-loaded datasets (such as FashionMNIST) that subclass <code> and implement functions specific to the particular data. They can be used to prototype and benchmark your model. You can find them here: Image Datasets, Text Datasets, and Audio Datasets.
