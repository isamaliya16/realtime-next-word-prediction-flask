Continually saving the "best" model or model weights/parameters has many benefits. These include being able to track the training progress and load saved models from different saved states.

In TensorFlow 1, to configure checkpoint saving during training/validation with the <code> APIs, you specify a schedule in <code> or use <code>. This guide demonstrates how to migrate from this workflow to TensorFlow 2 Keras APIs.

In TensorFlow 2, you can configure <code> in a number of ways:

Save the "best" version according to a metric monitored using the <code> parameter, where <code> can be, for example, <code>, <code>, <code>'val_accuracy'`.

Save continually at a certain frequency (using the <code> argument).

Save the weights/parameters only instead of the whole model by setting <code> to <code>.

For more details, refer to the <code> API docs and the Save checkpoints during training section in the Save and load models tutorial. Learn more about the Checkpoint format in the TF Checkpoint format section in the Save and load Keras models guide. In addition, to add fault tolerance, you can use <code> or <code> for manual checkpointing. Learn more in the Fault tolerance migration guide.
