This guide demonstrates how to migrate the single-worker multiple-GPU workflows from TensorFlow 1 to TensorFlow 2.

To perform synchronous training across multiple GPUs on one machine:

In TensorFlow 1, you use the <code> APIs with <code>.

In TensorFlow 2, you can use Keras Model.fit or a custom training loop with <code>. Learn more in the Distributed training with TensorFlow guide.

TensorFlow 2: Single-worker training with Keras.

When migrating to TensorFlow 2, you can use the Keras APIs with <code>.

If you use the <code> APIs for model building and Keras <code> for training, the main difference is instantiating the Keras model, an optimizer, and metrics in the context of <code>, instead of defining a <code> for <code>.

If you need to use a custom training loop, check out the Using tf.distribute.Strategy with custom training loops guide.
