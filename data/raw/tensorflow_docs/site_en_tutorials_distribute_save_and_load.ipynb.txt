Which API should I use?

For saving, if you are working with a Keras model, use the Keras <code> API unless you need the additional control allowed by the low-level API. If what you are saving is not a Keras model, then the lower-level API, <code>, is your only choice.

For loading, your API choice depends on what you want to get from the model loading API. If you cannot (or do not want to) get a Keras model, then use <code>. Otherwise, use <code>. Note that you can get a Keras model back only if you saved a Keras model.

It is possible to mix and match the APIs. You can save a Keras model with <code>, and load a non-Keras model with the low-level API, <code>.
