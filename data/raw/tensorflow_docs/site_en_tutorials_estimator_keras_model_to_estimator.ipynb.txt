Overview.

TensorFlow Estimators are supported in TensorFlow, and can be created from new and existing <code> models. This tutorial contains a complete, minimal example of that process.

Note: If you have a Keras model, you can use it directly with <code> strategies without converting it to an estimator. As such, <code> is no longer recommended.
